# ImmerseFree 完整版｜宣傳文案

你收藏了多少外文文章，卻一直沒讀完？
又有多少部影片，看懂了，卻沒把學到的東西留下來？

ImmerseFree 把翻譯放回你正在讀的地方，也把影片裡的字幕變成可以複習的教材。

讀文章，原文與譯文放在一起。卡在一句話，反白就能翻譯。看 YouTube，取得字幕後批次翻譯；想練英文，就從影片整理單字、例句與句型。追 Netflix、Disney+，也能對照平台提供的兩種語言字幕。

從 PDF、EPUB 到雙語 Word 匯出，讀懂的內容，還能帶走。

完整功能開放，不用訂閱 ImmerseFree。翻譯引擎由你選，模型服務的額度與費用依各自方案。

## 短版

看懂外文，只是開始。

ImmerseFree 完整版，把雙語網頁、影片字幕、影片學習與文件翻譯放進同一個瀏覽器。原文留著、譯文跟上，看過的影片也能變成單字與句型教材。
